# BallMill Ops

Operations-only ERP (orders, weighments, mill runs, maintenance, resin lining inspections) on Supabase. No finance.

1. Supabase SQL editor: run `schema.sql`.
2. Authentication > Users: add a login for each team member.
3. `cp .env.example .env` and fill in the project URL and anon key.
4. `npm install && npm run dev` (or `npm run build` and host `dist/`).
